# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。サービス名は subscription-tracker。画面に出す名前は「サブスクの支払い」。

## 1. 使う場面

- **使う人**（推定）：動画・音楽・クラウド保存・アプリなど、サブスクを5〜15件ほど契約している20〜40代。スマホの操作には慣れているが、表計算ソフトで管理するほどの手間はかけたくない人
- **使う場面**（推定）：
  - 最初の1回：思い出しながら、契約中のサブスクを5〜10件まとめて登録する（5分ほど、家でスマホかPC）
  - その後：カードの明細が来たとき、「いくら払っているんだろう」と気になったとき、解約を考えたときに開く。月に1〜3回、1回30秒〜1分。家のソファや電車の中
- **端末と姿勢**（推定）：スマホが主（7割）。片手で開いて見る。登録だけは両手で入力することもある。明るい部屋〜電車の中なので、明るい地にする
- **やりたいこと（優先順）**：
  1. 毎月いくら払っているかを知る（いちばん大事）
  2. 次にいつ、どれの更新が来るかを知る（解約するなら、その前に）
  3. サブスクを足す・金額や更新日を直す・解約した物を消す
- **見たい情報（優先順）**：
  1. 毎月の支払い合計
  2. 次の更新（日付・あと何日・名前・金額）
  3. これから30日の更新の並び（いつ引き落としが固まるか）
  4. 全部のサブスクの一覧（次の更新日が近い順）
  - 最初の1画面（スマホ 390×844）に、1・2・3と、一覧の先頭2〜3件と「サブスクを足す」ボタンを必ず入れる
- **気持ち**：開く前は「使いすぎているかも」という少しの不安。見たあとは「全部ここに出ている、把握できた」という落ち着き。数字を責めるような演出（赤い警告、大げさな強調）はしない
- **失敗すると困ること**：
  - 金額の桁や年払い・月払いの読み間違い（合計を信じて判断するので、いちばん困る）
  - 更新日の見落とし（解約し忘れて、もう1か月・1年分払ってしまう）
  - 間違えて消してしまう
  - 金額の入れ間違い（「1490」を「14900」など）

## 2. サービスの型と優先順位

**管理・記録の道具**。毎日ではないが、何度も開いて数字を読み、ときどき直す。

- 最優先：合計の数字の読みやすさ／次の更新が一目で分かること／入力の速さと間違えにくさ
- 抑える物：飾り・大きな演出・入ってくる動き。動きは、押した反応と、変わった所を見せる時だけ
- 質は、数字の桁揃え・整列・余白の精度で出す
- 題材から借りる物：カードの「利用明細」。日付・名前・金額が右揃えで縦に揃っている読みやすさ。見た目を明細書に似せるのではなく、その「揃っていて読み間違えない」性質だけを借りる
- 印象に残す物は1つだけ：**「これから30日」の帯**（今日から30日先までの線の上に、更新日の印が並ぶ）。サブスクの場面に固有の「いつ引き落としが来るか」をそのまま形にした物で、ほかは静かにする

## 3. 構図

### 共通

- すべて左揃え。金額だけ右揃え
- 画面の上から：題名 → 合計 → 次の更新 → これから30日の帯 → 一覧
- 一覧は「次の更新日が近い順」。先頭（＝次の更新）の行だけ、薄い青の地（`--accent-weak`）にする（上の「次の更新」と同じ物だと分かるように）
- 縦の間隔（スマホ）：上余白 20px → 題名 → 24px → 合計のラベル → 4px → 合計 → 4px → 年間・補足 → 16px → 区切り線 → 16px → 次の更新 → 16px → 区切り線 → 16px → 帯のラベル → 8px → 帯 → 4px → 目盛り → 16px → 一覧。ラベルと値の間は 4px。これで一覧の先頭まで約 430px、1行約 70px なので、390×844 では固定バー（72px＋安全域）より上に一覧の先頭3件まで入る

### スマホ（360〜1023px）

左右の余白 16px。600px 以上では、中身（固定バーのボタンも）を最大 640px にして中央に置く（タブレットで金額と名前が離れすぎないように）。画面の下に「サブスクを足す」ボタンを固定する（親指が届く所。登録が主な操作の1つなので）。

```
┌────────────────────────────┐ 390px
│ サブスクの支払い            │ 題名 20px 太字   上余白 20px
│                            │
│ 毎月の支払い                │ 13px 弱い文字
│ 12,340円                    │ 40px 太字（円は20px）左揃え
│ 年間 148,080円              │ 13px 弱い文字
│ 年払いは12で割って足しています │ 13px 弱い文字（年払いがある時だけ）
│ ────────────────────────── │ 区切り線
│ 次の更新                    │ 13px 弱い文字
│ 11月3日（あと5日）           │ 20px 太字
│ Netflix  1,490円／月         │ 16px
│ ────────────────────────── │
│ これから30日                │ 13px 弱い文字
│ ●───●──■────●──────●── │ 帯 高さ48px
│ 10/29  11/5  11/12 11/19 11/28│ 13px 弱い文字
│ ┌────────────────────────┐ │
│ │11/3  Netflix    1,490円│ │ 一覧（白い地の1枚の面）
│ │あと5日           ／月  │ │ 1行 最小64px
│ ├────────────────────────┤ │
│ │11/8  Spotify     980円 │ │
│ │あと10日          ／月  │ │
│ ├────────────────────────┤ │
│ │ …                      │ │
│ └────────────────────────┘ │
│                            │ 一覧の下に 96px の空き（固定ボタンに隠れないように）
├────────────────────────────┤
│ [      サブスクを足す      ] │ 固定バー：高さ 52px のボタン＋上下 10px
└────────────────────────────┘   ＋ env(safe-area-inset-bottom)
```

- 「サブスクを足す」を押すと、下から入力シート（6. の「入力シート（スマホ）」）が出る
- 一覧の行を押すと、同じシートが「直す」状態で出る
- 固定バーの地は `--bg`、上に 1px の `--line`

### PC（1024px 以上）

中身の幅は最大 1080px で中央寄せ、左右の余白 32px。2列：左 1fr（合計・次の更新・帯・一覧）、右 360px（入力欄をずっと出しておく。登録を何件も続けてするのはPCが多いので、開け閉めの手間を省く）。列の間 48px。右列は `position: sticky; top: 32px`。

```
┌──────────────────────────────────────────────────────────────┐
│ サブスクの支払い                                               │
│                                                              │
│ 毎月の支払い                 次の更新          │ サブスクを足す   │
│ 12,340円                    11月3日（あと5日） │ 名前 [        ] │
│ 年間 148,080円               Netflix 1,490円／月│ 金額 [      ]円 │
│                                              │ 周期 (毎月|毎年) │
│ これから30日                                   │ 次の更新日 [   ] │
│ ●────●──■───────●─────────●──────────     │ [  追加する  ]   │
│ 10/29   11/5    11/12    11/19     11/28     │                │
│ ┌──────────────────────────────────────────┐ │                │
│ │11/3 あと5日   Netflix          1,490円／月│ │                │
│ │11/8 あと10日  Spotify            980円／月│ │                │
│ └──────────────────────────────────────────┘ │                │
└──────────────────────────────────────────────────────────────┘
```

- 合計と次の更新は、左列の中で横に2つ並べる（左に合計、右に次の更新。間 48px）。次の更新の名前が長い時は1行で末尾を「…」（1024px で左列は約 550px あり、合計 48px と次の更新が並んで入る）
- 一覧の行は1行で横に並べる：日付 64px ／ あと何日 80px（13px）／ 名前（残り）／ 金額（右揃え）。金額のすぐ後ろに「／月」「／年」を 13px `--muted` で同じ行に置く。行の高さ 最小52px。年払いの行だけ、名前の下に「月あたり 1,300円」（13px `--muted`）を足し、行が高くなる
- 1440px より広い画面でも、中身は 1080px のまま中央に置く（金額と名前が離れすぎて読み間違えないように）
- 固定ボタンは出さない（右列の入力欄があるので）
- 上余白 32px、下余白 48px。合計と次の更新は横に並ぶので、その間の区切り線は出さない（次の更新と帯の間の線は残す）

### これから30日の帯

- 今日を左端、30日後を右端にした横線。線は高さ 2px、色 `--line-strong`、帯（高さ 48px）の上から 36px の所（重ねた印が上に入る場所を残す）。線の両端は帯の左右から 5px 内側（端の印が切れないように）
- 更新日ごとに印を置く。位置は「今日から何日後か ÷ 30」×線の長さ。印は直径 10px の丸、色 `--accent`
- あと3日以内（今日を含む）の印は、10px の四角、色 `--warn`（色だけでなく形でも分ける）
- 同じ日に2件以上あるときは、印を上に 12px ずつ重ねる（最大3つ。4件以上の時は、3つ目の印の右 4px に「+2」などを 13px `--muted` で書く）
- 下に日付の目盛りを5つ：今日・7日後・14日後・21日後・30日後。書き方は「10/29」。13px、`--muted`。今日の目盛りだけ「今日」と書く。左端の目盛りは左揃え、右端は右揃え、ほかは印の位置に中央揃え
- 帯は飾りではなく、一覧と同じ情報を形にした物。読み上げでは `aria-hidden="true"` にし、一覧で同じ情報を伝える
- 30日より先の更新しか無いときは、帯の中、線の上の右端に右揃えで「次は12月20日」と 13px `--muted` で書く（スマホでは帯の外に場所が無いので）

### 一覧の1行

- 左：日付（16px 太字、数字の書体）、その下に「あと5日」（13px、`--muted`。あと3日以内は `--warn` で「あと2日」「明日」「今日」）
- 中：名前（16px、1行。はみ出たら末尾を「…」）
- 右：金額（16px 太字、数字の書体、右揃え）、その下に「／月」か「／年」（13px、`--muted`）。年払いの行は、名前の下に「月あたり 1,300円」（13px、`--muted`）も書く
- スマホでは、左の列（日付・あと何日）の幅 72px、列の間 12px。PC では名前と金額の間 16px
- 行全体が1つのボタン（押すと直す）。行の間は 1px の `--line`
- 一覧は白い地（`--surface`）の1枚の面。枠 1px `--line`、角丸 8px。行を別々の箱にしない

## 4. 色

明るい部屋や電車の中で読むので、明るい地。地は白に近い少し青みのある灰色（カードの明細の紙の冷たさ）。強調は落ち着いた濃い青1色だけにし、注意（更新が近い）と失敗だけに別の色を使う。

| 名前 | 値 | 用途 | コントラスト比 |
| --- | --- | --- | --- |
| `--bg` | `#F2F4F3` | ページの地 | — |
| `--surface` | `#FFFFFF` | 一覧の面・入力欄・入力シートの地 | — |
| `--text` | `#1C2B33` | 本文・金額・合計 | `--bg` に 13.2:1、`--surface` に 14.6:1 |
| `--muted` | `#566770` | 弱い文字（ラベル・あと何日・目盛り・補足） | `--bg` に 5.3:1、`--surface` に 5.9:1、`--accent-weak` に 5.0:1 |
| `--line` | `#D3DCDE` | 区切り線・一覧の枠（飾りの線。比率は問わない） | — |
| `--line-strong` | `#7A8A92` | 入力欄の枠・帯の線 | `--surface` に 3.6:1（枠は 3:1 以上） |
| `--accent` | `#1D5C8C` | 主なボタンの地・帯の印・フォーカスの輪・リンク | `--surface` に 7.1:1、`--bg` に 6.4:1 |
| `--accent-hover` | `#174A72` | 主なボタンに乗せた時・押した時 | 白い文字に 9.3:1 |
| `--accent-weak` | `#E6EEF5` | 次の更新の行の地・周期の選んだ側の地 | `--text` に 12.4:1、`--accent` に 6.1:1 |
| `--on-accent` | `#FFFFFF` | 主なボタンの文字 | `--accent` に 7.1:1 |
| `--warn` | `#8A4B00` | あと3日以内の文字・帯の四角い印 | `--surface` に 6.8:1、`--bg` に 6.2:1、`--warn-weak` に 6.1:1、`--accent-weak`（次の更新の行）に 5.8:1 |
| `--warn-weak` | `#FFF1D6` | 「次の更新」があと3日以内のときの、その日付の文字の地（左右 4px の余白） | — |
| `--error` | `#B42318` | 入力のエラー・削除の文字 | `--surface` に 6.6:1、`--bg` に 6.0:1 |
| `--toast-bg` | `#1C2B33` | 下に出るお知らせの地（`--text` と同じ値） | 白い文字に 14.6:1 |
| `--disabled-bg` | `#E3E8E9` | 使えないボタンの地 | `--muted` の文字に 4.8:1 |

- 色だけで意味を伝えない：更新が近いことは「あと2日」の文字と四角い印で、エラーは文章と「!」の印で、次の更新の行は上の「次の更新」と同じ内容（日付・名前・金額）で伝える
- 影は、入力シートとお知らせにだけ `0 -2px 12px rgba(28, 43, 51, 0.12)`（下から出る物が上に重なっていると分かるように）。一覧・入力欄には付けない
- 角丸：一覧の面と入力シートの上側 8px、ボタン・入力欄 6px、帯の印は丸か四角そのまま。全部を同じ丸さにしない

## 5. 文字

- 書体（Google Fonts。`next/font/google` で読み込む。依存パッケージは増やさない）
  - 見出し・本文：**BIZ UDPGothic**（400・700）。読み間違いを減らすために作られたユニバーサルデザインの書体で、小さい文字や電車の中で読んでも形がつぶれにくい
  - 金額・日付・あと何日の数字：**BIZ UDGothic**（400・700）。同じ一族の等幅版で、数字の幅がすべて同じなので、一覧の金額の桁が縦に揃う。「1」と「7」、「0」と「8」が見分けやすい。さらに `font-variant-numeric: tabular-nums` を付ける
  - 金額の入力欄も BIZ UDGothic にする（入れた桁が数えやすいように）
- 大きさの段（5段）

| 段 | 大きさ | 行の高さ | 太さ | 使う所 |
| --- | --- | --- | --- | --- |
| 補足 | 13px | 1.5 | 400 | ラベル（毎月の支払い・次の更新・これから30日）、あと何日、目盛り、／月、エラーの文 |
| 本文 | 16px | 1.6 | 400（金額と日付は700） | 一覧、入力欄、ボタン、次の更新の名前と金額 |
| 見出し | 20px | 1.4 | 700 | 題名「サブスクの支払い」、次の更新の日付、入力シートの題名 |
| 合計（スマホ） | 40px | 1.1 | 700 | 毎月の支払い合計の数字 |
| 合計（PC） | 48px | 1.1 | 700 | 同上（1024px 以上） |

- 合計の「円」は「見出し」の段の 20px（スマホ・PC とも。段を増やさないため）、400、数字との間 2px。数字と同じ下の線に揃える
- 金額は3桁ごとに「,」。通貨は「円」を後ろに付ける（「¥」は使わない）
- 日付：一覧と目盛りは「11/3」、次の更新は「11月3日」。年が今年と違うときだけ「2027/1/5」「2027年1月5日」
- ラベルに全部大文字や字間を広げる飾りは使わない
- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- 日本語は文節の途中で切らない（`word-break: auto-phrase`）

## 6. 部品と状態

フォーカスはすべて共通：`outline: 2px solid var(--accent); outline-offset: 2px`（キーボードで動かした時だけ。`:focus-visible`）。ただし、お知らせ（暗い地）の中だけは輪を `#FFFFFF` にする（`--accent` は `--toast-bg` に 2.1:1 で見えないため。白は 14.6:1）。

### 主なボタン（サブスクを足す・追加する・変更を保存）

| 状態 | 見え方 |
| --- | --- |
| 通常 | 地 `--accent`、文字 `--on-accent` 16px 700、高さ 52px（スマホ）／48px（PC）、角丸 6px、左右 20px。スマホの固定バーでは横幅いっぱい |
| 乗せた | 地 `--accent-hover`、カーソルは手の形 |
| 押した | 地 `--accent-hover`、`transform: translateY(1px)` |
| フォーカス | 共通の輪 |
| 使えない | 地 `--disabled-bg`、文字 `--muted`。保存中だけ使う（文言は「保存中…」） |

### 弱いボタン（閉じる・やめる・元に戻す）

- 地なし、文字 `--accent` 16px 700、高さ 44px、左右 12px。乗せた時は下線、押した時は地 `--accent-weak`
- お知らせの中の弱いボタン（「元に戻す」「閉じる」）は文字を白、乗せた時・押した時は下線（地は付けない）

### 削除のボタン

- 入力シート（直す時）の左下に置く。地なし、文字 `--error` 16px 400「このサブスクを削除」、高さ 44px。乗せた時は下線
- 主なボタンから 24px 以上離す（押し間違い防止）

### 入力欄（名前・金額・次の更新日）

- ラベルは欄の上、16px 700、欄との間 6px。欄どうしの間 20px
- 欄：高さ 48px、地 `--surface`、枠 1px `--line-strong`、角丸 6px、左右 12px、文字 16px（スマホで拡大されないように 16px 未満にしない）

| 状態 | 見え方 |
| --- | --- |
| 通常 | 上のとおり。空の時の薄い例文は `--muted`：名前「例：Netflix」、金額「例：1490」 |
| 乗せた | 枠 `--text` |
| フォーカス | 枠 2px `--accent`（中の文字が動かないよう、通常時から内側に 1px の余白を足しておく）。共通の輪は付けない |
| エラー | 枠 2px `--error`、欄の下 6px に「!」の丸印（直径 16px、`--error` の地に白い「!」）とエラーの文 13px `--error`。`aria-invalid="true"`、文は `aria-describedby` で結ぶ。エラーの欄にフォーカスがある時は、枠は `--error` のまま、外に共通の輪を付ける |
| 使えない | 地 `--disabled-bg`、文字 `--muted`（保存中だけ） |

- 金額：`inputmode="numeric"`、右に「円」を欄の中に固定で表示（16px `--muted`）。入力中も3桁ごとの「,」は入れない（打ち間違いを避ける）。欄から出た時に、欄の下へ「1,490円」と 13px `--muted` で読み返しを出す（桁の入れ間違いに気づけるように）
- 次の更新日：`<input type="date">`。最初は空
- 名前：`autocomplete="off"`、最大30文字
- 最後の欄と主なボタンの間は 24px。主なボタンは入力欄と同じ横幅

### 周期の選択（毎月・毎年）

- 2つ並びの切り替え。全体の高さ 48px、枠 1px `--line-strong`、角丸 6px。中は半分ずつ、間に 1px の `--line-strong`
- 選んだ側：地 `--accent-weak`、文字 `--accent` 700、文字の前に「✓」。選んでいない側：地 `--surface`、文字 `--text` 400
- 乗せた：選んでいない側の地を `--bg`
- フォーカス：共通の輪（全体に）。矢印キーで切り替える（`role="radiogroup"`）
- 最初は「毎月」を選んだ状態（推定：多くのサブスクは月払い）

### 一覧の行

| 状態 | 見え方 |
| --- | --- |
| 通常 | 3. の「一覧の1行」のとおり。左右 16px、上下 12px |
| 乗せた | 地 `--bg` |
| 押した | 地 `--accent-weak` |
| フォーカス | 共通の輪（`outline-offset: -2px` で面の内側に） |
| 次の更新の行 | 地 `--accent-weak`（乗せても変えない） |

### 入力シート（スマホ）

- 下から出る。地 `--surface`、上の角丸 8px、高さは中身に合わせ最大で画面の 90%。後ろは `rgba(28, 43, 51, 0.4)` で暗くする
- 内側の余白は上 8px・左右 16px・下 16px＋`env(safe-area-inset-bottom)`
- 上に題名（20px 700「サブスクを足す」か「サブスクを直す」）、右上に弱いボタン「閉じる」。題名と最初の欄の間 12px
- 下に主なボタンを横幅いっぱい。直す時は、その上の左に「このサブスクを削除」
- 後ろを押す・Esc・「閉じる」で閉じる。入れかけの内容があるときは閉じる前に確かめない（次に開いた時に残しておく）
- 開いた時は「名前」の欄にフォーカス。開いている間はフォーカスをシートの中に留め（`role="dialog"`・`aria-modal="true"`）、閉じたら開く前に押した物（ボタンか一覧の行）へ戻す

### 入力欄（PC の右列）

- 題名「サブスクを足す」（20px 700）。下に入力欄と「追加する」。題名と最初の欄の間 20px
- 一覧の行を押すと、右列が「サブスクを直す」に変わり、その行の内容が入る。主なボタンは「変更を保存」、横に弱いボタン「やめる」、下に「このサブスクを削除」
- 直している行は、一覧で内側に 2px の `--accent` の枠（`box-shadow: inset 0 0 0 2px var(--accent)`）を付ける（どれを直しているか分かるように。行の大きさは変えない）
- 直す時の下の並び（上から）：「変更を保存」（「やめる」の残りの幅いっぱい）と「やめる」を横に並べ（間 8px、弱いボタンは右）、その下 24px 空けて「このサブスクを削除」（左揃え）。最後の欄と「変更を保存」の間は 24px
- スマホの入力シート（直す時）は、最後の欄の下 24px に「このサブスクを削除」（左揃え）、その下 24px に主なボタン「変更を保存」（横幅いっぱい）。「やめる」は出さない（右上の「閉じる」があるため）。削除と主なボタンの間は 24px 以上空ける
- 「このサブスクを削除」は文字だけの弱い見た目なので、主なボタンと同じ行・同じ塊には置かない

### お知らせ（追加・保存・削除の後）

- 画面の下から 16px（スマホは固定バーの上 8px）、横は中央。最大幅 420px、地 `--toast-bg`、文字白 16px、角丸 6px、左右 16px・上下 12px
- 4秒で消える。削除の時だけ「元に戻す」を付けて 8秒
- 「元に戻す」は、文言の右に置く弱いボタン（お知らせの中の弱いボタン。文字を白）。押すと「「Netflix」を元に戻しました」（4秒）に変わる
- `role="status"`

## 7. 空・読み込み中・エラー

### 空（1件も無い時）

- 合計は「0円」を出す（数字の場所を最初から見せて、何が出るかを分からせる）
- 「次の更新」と帯と一覧の代わりに、左揃えの文を出す：
  - 1行目（16px 700）「まだサブスクが登録されていません」
  - 2行目（16px 400 `--muted`）「契約中のサブスクの名前・金額・次の更新日を入れると、毎月の合計と、次に更新が来るものがここに出ます。」
  - 3行目（16px 400 `--muted`）スマホ「下の「サブスクを足す」から入れられます」、PC「右の欄から入れられます」
  - スマホ：ボタンは画面の下の固定バーの1つだけ（主なボタンを1画面に2つ出さない。親指の届く所で始められる）
  - PC：右列の入力欄がすでに出ているので、ボタンは置かない。名前の欄に最初からフォーカス
- 絵や絵文字は置かない

### 読み込み中

- 保存先（この端末）から読むのは一瞬なので、回る印は出さない
- 読み終わるまで、合計の場所に「読み込み中…」（16px `--muted`）を出し、ほかは出さない（「0円」を一瞬見せて誤解させないように）

### エラー

- 入力のエラー（欄の下に出す。保存はしない。最初のエラーの欄にフォーカスを移す）
  - 名前が空：「名前を入れてください」
  - 金額が空・数字でない：「金額を数字で入れてください（例：1490）」
  - 金額が0以下：「1円以上で入れてください」
  - 次の更新日が空：「次の更新日を選んでください」
  - 次の更新日が今日より前：「今日以降の日付を選んでください」（「あと-3日」のような表示を出さないため）
- 保存できなかった時（この端末に保存できない設定など）：お知らせを `--error` の地ではなく通常の地で出し、文言は「保存できませんでした。ブラウザの設定で、このサイトの保存が許可されているか確かめてください」。消さずに残し、「閉じる」を付ける

## 8. 動き

| 何が | いつ | 時間 | 曲線 |
| --- | --- | --- | --- |
| ボタン・行の地の色 | 乗せた・押した | 80ms | `ease-out` |
| 入力シート | 開く（下から上へ） | 200ms | `cubic-bezier(0.2, 0, 0, 1)` |
| 入力シート | 閉じる（上から下へ） | 150ms | `cubic-bezier(0.4, 0, 1, 1)` |
| 後ろの暗さ | シートと一緒 | 同じ時間 | 同じ曲線 |
| 足した・直した行 | 保存した直後、その行の地が `--accent-weak` から通常へ | 1200ms | `ease-out` |
| お知らせ | 出る・消える（透明度だけ） | 150ms | `ease-out` |

- 合計の数字は、数えあがる動きにしない（途中の数字を読み間違えるので）。すぐ新しい値にする。読み上げ用に合計の場所を `aria-live="polite"` にする
- ページを開いた時の入ってくる動きは付けない
- `prefers-reduced-motion: reduce` の時は、上の動きをすべて止め、すぐ変える（足した行の地の色も付けない）

| 場所 | 文言 |
| --- | --- |
| ページの題名（`<title>` と h1） | サブスクの支払い |
| 合計のラベル | 毎月の支払い |
| 年間 | 年間 148,080円 |
| 年払いがある時の補足 | 年払いは12で割って足しています |
| 次の更新のラベル | 次の更新 |
| 次の更新の日付 | 11月3日（あと5日）／ 明日 ／ 今日 |

| 帯のラベル | これから30日 |

| 周期 | 毎月 ／ 毎年（一覧の金額の下は「／月」「／年」） |
| 年払いの月あたり | 月あたり 1,300円（1円未満は四捨五入） |
| 足すボタン | サブスクを足す |
| 入力シートの題名 | サブスクを足す ／ サブスクを直す |
| 入力欄のラベル | 名前 ／ 金額 ／ 支払いの周期 ／ 次の更新日 |

- 「登録」「データ」「レコード」など作る側の言葉は使わない。「サブスク」で統一する
- 動作の名前を通して揃える：「足す」→「追加しました」、「変更を保存」→「変更を保存しました」、「削除」→「削除しました」
- 謝らない（「申し訳ありません」は使わない）。何が起きて、どうすればいいかを書く

## 10. 避けること

- 合計を、数字を大きく並べたタイルにしない（合計・年間・件数を同じ大きさの箱で3つ並べる、など）。目立たせるのは「毎月の支払い」の1つだけ。年間は補足の大きさ
- 合計の数字にグラデーションや色を付けない（`--text` のまま）。増えたことを赤で責めない
- 一覧を角丸の箱を並べただけのカードにしない。1枚の面を線で区切る
- 金額の桁がずれる書体や、左揃えの金額にしない（読み間違いの元）
- 年払いの金額を、月払いと区別せずに並べない（必ず「／年」と「月あたり」を添える）
- 更新が近いことを色だけで伝えない（「あと2日」の文字と四角い印を必ず添える）
- 削除を主なボタンの隣に置かない。削除前に確かめる画面は出さず、「元に戻す」で取り消せるようにする
- ピル型バッジの多用（「月額」「年額」「もうすぐ」などを丸い札にして並べない）、絵文字、グラデーション、大きな塗りつぶしボタンの羅列（主なボタンは1画面に1つ）
- AIが作った感：クリーム色の地とテラコッタの強調、黒い地に1色だけの蛍光色、新聞風の細い罫線だらけの組み方、同じ角丸と同じ薄い影を全部に付けること、見出しの上の全部大文字の小さなラベル、「A · B · C」の点つなぎ、ボタンの文字の後ろの「→」、小さなラベルだけ等幅書体、見出しの1語だけ色や太さを変えること
- 01・02・03 の番号付け（一覧は順番の手順ではないので付けない）
- 1440px より広い画面で、中身を横いっぱいに伸ばすこと

## 検査

確かめた項目（進め方「5. 検査する」）：

- 場面と構図のつながり：合計 → 次の更新 → 帯 → 一覧の順と、下に固定したボタンは、どれも「使う場面」の優先順と片手での利用から理由がついている。問題なし
- スマホ 390×844 の最初の1画面：縦の間隔が書かれておらず確かめられなかった → 縦の間隔を足して数えた（一覧の先頭まで約 430px＋3行で約 640px。固定バーより上に入る）
- コントラスト比：表の値を計算し直し、すべて合っていた。`--warn` を `--bg`・`--accent-weak`（次の更新の行）に置く組み合わせが抜けていた → 足した（6.2:1・5.8:1）
- フォーカスの見え方：お知らせ（暗い地）の中では `--accent` の輪が 2.1:1 で見えない → お知らせの中だけ白い輪にした。エラーの欄にフォーカスがある時の見え方と、入力シートのフォーカスの扱い（中に留める・閉じたら戻す）も足した
- 押す所の大きさ：どれも 44px 以上。問題なし
- 色だけに頼っていないか：四角い印・「あと2日」・「✓」・「!」の印が添えてある。問題なし
- 空の状態：スマホで主なボタンが2つ（固定バー＋文の下）になり、「主なボタンは1画面に1つ」と食い違っていた → 文の下のボタンをやめ、どこから始めるかを3行目の文で示した
- 型に合っているか：管理・記録の道具として、動きは反応だけ、印象に残す物は帯の1つだけ。問題なし
- 広い画面：PC は最大 1080px で中央、1024px でも左列に合計と次の更新が並んで入る。600〜1023px（タブレット）では一覧が横いっぱいに伸びていた → 最大 640px で中央に置いた。PC の一覧で年払いの行と「／月」の置き方が決まっていなかった → 書いた
- よくある見た目・AIが作った感：クリーム地・黒地に蛍光色・新聞風・同じカードの羅列・全部大文字のラベル・「→」に当てはまらない。数字だけの等幅書体は、小さな飾りのラベルではなく金額の桁揃えのためなので残した。題材（カードの利用明細の揃い方と「いつ引き落としが来るか」の帯）から決めている

ほかに直した所：

- 合計の「円」が PC で 24px になり、文字の段が6段になっていた → スマホ・PC とも 20px にした
- スマホの図で合計が右寄りに描かれていた → 左揃えに描き直した。「7. の入力シート」「2. の次の更新」の参照の間違いを直した
- 帯：線を上下中央に置くと3つ重ねた印と「+2」がはみ出す → 線を上から 36px に下げ、「+2」は印の右に。端の印が切れないよう線を 5px 内側に。「次は12月20日」をスマホでも入る帯の中に移した
- 次の更新日に過去の日付を入れた時のエラーの文言を足した
