# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

契約中のサブスクの名前・金額・更新日を登録すると、毎月の支払い合計と次に更新が来るサブスクがひと目で分かるページ。（元のメモ：入っているサブスクの名前・金額・更新日を入れると、毎月いくら払っているかと、次に更新が来る物がひと目で分かるページ）

## 前提

- 使う人・使う場面（デザイン部門の分析。推定を含む）：
  - 使う人（推定）：動画・音楽・クラウド保存などのサブスクを5〜15件ほど契約している20〜40代。スマホの操作には慣れているが、表計算ソフトで管理するほどの手間はかけたくない人
  - 使う場面（推定）：最初に家で契約中のサブスクを5〜10件まとめて登録する（5分ほど）。その後は、カードの明細が来たときや解約を考えたときに、スマホで片手で開いて合計と次の更新を見る（月に1〜3回、1回30秒〜1分。家や電車の中）
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
