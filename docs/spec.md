# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

契約中のサブスクの名前・金額・更新日を登録すると、毎月の支払い合計と次に更新が来るサブスクがひと目で分かるページ。（元のメモ：入っているサブスクの名前・金額・更新日を入れると、毎月いくら払っているかと、次に更新が来る物がひと目で分かるページ）

## 前提

- 使う人・使う場面（デザイン部門の分析。推定を含む）：
  - 使う人（推定）：動画・音楽・クラウド保存などのサブスクを5〜15件ほど契約している20〜40代。スマホの操作には慣れているが、表計算ソフトで管理するほどの手間はかけたくない人
  - 使う場面（推定）：最初に家で契約中のサブスクを5〜10件まとめて登録する（5分ほど）。その後は、カードの明細が来たときや解約を考えたときに、スマホで片手で開いて合計と次の更新を見る（月に1〜3回、1回30秒〜1分。家や電車の中）
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

ページは1つ（`/`）。見た目は `docs/design.md` のとおり。

### データの持ち方

- サブスク1件は「名前（1〜30文字）・金額（1以上の整数、円）・周期（毎月か毎年）・次の更新日（`YYYY-MM-DD`）」と、見分けるための id を持つ
- この端末のブラウザ（localStorage、キーは `subscription-tracker.subscriptions`）に、全件を JSON の配列で保存する。サーバーには送らない
- 読めない時（保存が許可されていない設定など）や、中身が壊れている時（JSON でない・配列でない）は、0件として扱う。配列の中の形が合わない1件だけは捨てて、ほかは使う
- 保存できなかった時は、一覧に足さず、入れた内容は欄に残したまま、`design.md` 7. の「保存できませんでした…」のお知らせを出す（消えずに残り、「閉じる」で消す）

### 次の更新日の決め方

- 「今日」は、この端末の日付で決める
- 保存した次の更新日が今日以降なら、その日が次の更新日
- 今日より前になっていたら、周期ぶん進めて、今日以降になる最初の日を次の更新日として扱う（保存した値はそのまま。表示の時に毎回計算する）
  - 毎月：1か月ずつ進める。その月に同じ日が無い時は、その月の最終日にする（1月31日 → 2月28日 → 3月31日。保存した日を基準に数えるので、一度丸めても次の月は元の日に戻る）
  - 毎年：1年ずつ進める。2月29日は、うるう年でない年は2月28日にする
- 「あと何日」は、今日から次の更新日までの日数。0日は「今日」、1日は「明日」、2日以上は「あと5日」。0〜3日を「あと3日以内」とする

### 合計

- 毎月の支払い：毎月のサブスクは金額、毎年のサブスクは「月あたり」（金額 ÷ 12 を1円未満四捨五入した額。一覧に出す「月あたり」と同じ値）を足す
- 年間：毎月のサブスクは金額 × 12、毎年のサブスクは金額をそのまま足す
- 毎年のサブスクが1件でもある時だけ「年払いは12で割って足しています」を出す
- 0件の時は「0円」

### 次の更新

- 次の更新日がいちばん近いサブスクを出す：日付（「11月3日（あと5日）」。明日・今日は「11月4日（明日）」「10月29日（今日）」）、名前、金額と「／月」か「／年」
- 同じ日に2件以上ある時は、一覧で先に来る物の名前に「ほか○件」を付け、金額はその日の全部の合計（「Netflix ほか1件 2,470円」。周期は付けない）
- あと3日以内の時は、日付の文字を `--warn`、地を `--warn-weak` にする

### これから30日の帯

- 今日（左端）から30日後（右端）までに次の更新日があるサブスクを、日ごとに1つの印にまとめて並べる。位置は「今日から何日後か ÷ 30」
- あと3日以内の日は四角い印、ほかは丸い印。同じ日に2件以上は上に重ねる（最大3つ。4件以上は3つ目の右に「+（件数−3）」）
- 下の目盛りは今日・7日後・14日後・21日後・30日後
- 30日後までに1件も無い時は、帯の中に「次は12月20日」（いちばん近い次の更新日）を出す
- 帯は読み上げない（`aria-hidden="true"`）。同じ情報は一覧で伝える

### 一覧

- 全部のサブスクを、次の更新日が近い順に並べる。同じ日は追加した順
- 1行に、日付（「11/3」）・あと何日・名前・金額・「／月」か「／年」。毎年の行には「月あたり 1,300円」も出す
- 先頭の行（＝次の更新）だけ地を `--accent-weak` にする
- 日付は、年が今年と違う時だけ年を付ける（「2027/1/5」「2027年1月5日」）。金額は3桁ごとに「,」を入れて後ろに「円」
- 行を押すと、そのサブスクを直せる（次の「直す」）

### 追加

- スマホ（1023px 以下）は、下に固定した「サブスクを足す」で入力シートを開いて入れる。PC（1024px 以上）は右列の入力欄にいつも入れられる
- 欄は 名前・金額・支払いの周期（最初は「毎月」）・次の更新日（最初は空）
- 「追加する」を押した時に検査する。エラーがあれば保存せず、エラーのある欄すべての下に文を出し、上から見て最初のエラーの欄（名前 → 金額 → 次の更新日）にフォーカスを移す
  - 名前が空（前後の空白は取り除いて数える）：「名前を入れてください」
  - 金額が空・整数でない：「金額を数字で入れてください（例：1490）」。全角数字と「,」は受け付けて数字に直す
  - 金額が0以下：「1円以上で入れてください」
  - 次の更新日が空：「次の更新日を選んでください」
  - 次の更新日が今日より前：「今日以降の日付を選んでください」
- エラーの欄を直し始めたら、その欄のエラーは消す
- 金額の欄から出た時、正しい金額なら欄の下に「1,490円」と読み返しを出す
- 保存できたら：欄を空に戻し（周期は「毎月」に戻す）、お知らせ「「Netflix」を追加しました」を4秒出し、足した行の地を `--accent-weak` から通常へ 1200ms で戻す
  - スマホ：シートを閉じ、「サブスクを足す」へフォーカスを戻す
  - PC：続けて入れられるよう、名前の欄にフォーカスを戻す

### 直す

- 一覧の行を押すと、そのサブスクの内容が入った入力欄が「サブスクを直す」で出る。次の更新日には、一覧に出している日（保存した日が過ぎていて進めた後の日）を入れる
  - スマホ：追加と同じ入力シートが「サブスクを直す」で出る。「名前」の欄にフォーカス
  - PC：右列が「サブスクを直す」に変わり、押した行の内容が入る。直している行には内側 2px の `--accent` の枠が付く（`design.md` 6.）。「名前」の欄にフォーカス。ほかの行を押すと、その行の内容に切り替わる
- 直す時の入力検査は追加と同じ（同じエラー文、最初のエラーの欄にフォーカス、直し始めたらその欄のエラーが消える、金額の読み返し）。直している間の入力は、追加の入れかけとは別に持つ（追加の入れかけは消えない）
- 「変更を保存」を押して検査を通ったら、その1件を書き換えて保存する（id と、追加した順は変えない）。一覧・合計・次の更新・帯にすぐ反映され、リロードしても残る
  - お知らせ「「Netflix」の変更を保存しました」を4秒出し、直した行の地を `--accent-weak` から通常へ 1200ms で戻す。名前を直した時は、新しい名前を出す
  - スマホ：シートを閉じ、押した行へフォーカスを戻す。PC：右列を「サブスクを足す」に戻し（欄は追加の入れかけ）、押した行へフォーカスを戻す
  - 保存できなかった時は、変更を反映せず、入れた内容は欄に残したまま、`design.md` 7. の「保存できませんでした…」を出す（追加と同じ）
- 直さずにやめる：スマホは「閉じる」・後ろを押す・Esc で閉じる（直している内容は捨てる。確かめない）。PC は「やめる」で右列を「サブスクを足す」に戻し、押した行へフォーカスを戻す。直している間にそのサブスクが無くなった時（ほかのタブで消した時など）も、「サブスクを足す」に戻る

### 削除と元に戻す

- 「このサブスクを削除」（直す時の入力欄にだけある）を押すと、確かめる画面は出さず、すぐ消して保存する。一覧・合計・次の更新・帯にすぐ反映される（0件になれば空の表示に戻る）
- お知らせ「「Netflix」を削除しました」に弱いボタン「元に戻す」を付けて、8秒出す
  - スマホ：シートを閉じ、「サブスクを足す」へフォーカスを戻す。PC：右列を「サブスクを足す」に戻し、名前の欄にフォーカス
- 「元に戻す」を押すと、消す前と同じ位置（同じ id、同じ内容、追加した順）に戻して保存し、お知らせ「「Netflix」を元に戻しました」を4秒出す。戻した行の地は `--accent-weak` から通常へ 1200ms で戻す
- 元に戻せるのは直前に消した1件だけで、そのお知らせが出ている間だけ。別のお知らせが出たら（追加・保存・もう1件削除など）、前の「元に戻す」は使えなくなる
- 削除を保存できなかった時は、消さずに、「保存できませんでした…」を出す。元に戻すを保存できなかった時も同じ
- 削除の履歴は持たない

### 空・読み込み中

- 0件の時：合計に「0円」、その下に `design.md` 7. の「まだサブスクが登録されていません」の3行を出す。次の更新・帯・一覧は出さない。PC では名前の欄に最初からフォーカス
- 端末から読み終わるまでは、合計の場所に「読み込み中…」だけを出す（入力欄・固定バーも出さない）
