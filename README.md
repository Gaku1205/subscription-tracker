# subscription-tracker

契約中のサブスクの名前・金額・更新日を登録すると、毎月の支払い合計と次に更新が来るサブスクがひと目で分かるページ。

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（入っているサブスクの名前・金額・更新日を入れると、毎月いくら払っているかと、次に更新が来る物がひと目で分かるページ）から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
